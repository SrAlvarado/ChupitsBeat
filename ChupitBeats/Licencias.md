# Licencias — guía rápida

Resumen práctico de qué puedes hacer con cada tipo de audio. Relacionado: [[Recursos - Música royalty-free]], [[Recursos - Sample packs]], [[Recursos - MIDI y melodías]].

## Tipos de licencia

| Licencia | ¿Atribución? | ¿Uso comercial? | Notas |
|---|---|---|---|
| **CC0 / Dominio público** | No | Sí | Lo más libre. Usar, modificar, vender. Sin créditos. |
| **CC-BY** | Sí | Sí | Libre incluso comercial, pero **debes acreditar** al autor. |
| **CC-BY-SA** | Sí | Sí | Como BY pero lo derivado hereda la misma licencia (*share-alike*). |
| **CC-BY-NC** | Sí | **No** | Solo usos **no comerciales**. |
| **Royalty-free** | Depende | Normalmente sí | Pagas (o es gratis) una vez y no pagas regalías por uso. **No** puedes revender el sample suelto. |
| **Stream-safe (tipo NCS)** | Sí | Limitado | Pensado para YouTube/Twitch con crédito; **no** es libre para todo. |

## Matices por plataforma (¡importante!)

- **NCS (NoCopyrightSounds):** gratis para **YouTube/Twitch/redes con atribución**. NO es royalty-free universal: para una release musical propia o una app necesitas licencia aparte.
- **Looperman:** los loops son gratis para usar en **tus producciones** (comerciales o no). **No** puedes redistribuir el loop tal cual ni meterlo en un sample pack. Cada loop puede pedir crédito.
- **Freesound:** licencia **por archivo** (CC0, CC-BY, CC-BY-NC, Sampling+). Hay que mirar cada sonido.
- **Pixabay / Uppbeat:** "Content License" propia, royalty-free, normalmente **sin atribución** (Uppbeat a veces pide crédito en plan free). No revender el archivo suelto.
- **Jamendo:** descarga gratis para uso **personal/no comercial** (CC). Para comercial → **Jamendo Licensing** (de pago).
- **ccMixter / Free Music Archive:** licencia **por pista** (desde CC0 hasta BY-NC). Filtrar por licencia.
- **Sample packs (Cymatics, Splice, Loopmasters, Teknovault…):** royalty-free para usar en producciones; **no** revender los samples.

## Regla de oro para Chupits Beat
La app **genera audio en tiempo real con síntesis (Strudel)** y samples del motor (909/808 ya incluidos en superdough). Eso evita el problema de copyright de raíz: no reproducimos tracks ajenos. Los recursos de este vault sirven como **referencia, inspiración y para entrenar/ajustar paletas**, no para reproducir tal cual. Ver [[Aplicación a Chupits Beat]].
