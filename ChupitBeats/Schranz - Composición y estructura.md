# Schranz — Composición y estructura

Cómo se compone y arregla un track. Relacionado: [[Schranz - Tempo y subdivisión]], [[Schranz - Diseño del kick]], [[Transiciones DJ]].

## Filosofía del género
- **Rítmico y tímbrico, casi sin melodía/armonía.** Todo es groove, timbre e intensidad.
- Construido sobre **loops que evolucionan cada 16–32 compases** (no hay verso/estribillo).
- **Cambios incrementales:** entra/sale un elemento, se abre un filtro, sube la distorsión.
- Pistas largas y **DJ-friendly** (intros/outros de batería limpios para mezclar).

## Estructura de un track (5 partes)
1. **Intro** (~32–64 bars): empieza escaso — solo kick + percusión ligera o atmósfera filtrada. Pensado para mezclar.
2. **Build-up:** añade capas y tensión; filtro abriéndose, percusión rodante.
3. **Breakdown / break:** quita el kick, sube tensión — *snare rolls*, ruido blanco creciente, *filter sweeps*.
4. **Drop:** vuelven kick + bass con toda la energía (el 2º drop suele ser el más potente).
5. **Outro:** se desmonta hacia batería limpia para la mezcla.

Patrones de arreglo habituales: **ABCABC**, **ABAB**, **BCB**.

## Curva de energía (el "arco" del DJ)
```
energía
  ▲        ____peak____            ____peak2 (más fuerte)
  │      /            \          /
  │  build             break    drop
  │ /                    \____ /
  └─────────────────────────────────────► tiempo
intro                                   outro
```

## Componentes por importancia
1. **Kick** — el cimiento (ver [[Schranz - Diseño del kick]]).
2. **Hi-hats** — corcheas/semicorcheas + open hat en offbeat.
3. **Clap / snare / rim** — en tiempos 2 y 4.
4. **Loops de percusión** — metales, scrapes industriales, loops rodantes (euclid).
5. **Stabs / ruido** — atonales, percusivos, de tensión.
6. **Bajo** — escaso, sidechain al kick.
7. **FX** — distorsión, bitcrush, compresión de bus, *filter sweeps*, *risers*, *sweepdowns*.

Ver el reparto en pistas en [[Schranz - Percusión y bajo]] y [[Aplicación a Chupits Beat]].
