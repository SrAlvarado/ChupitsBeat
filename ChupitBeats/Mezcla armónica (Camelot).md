# Mezcla armónica (Camelot Wheel)

Mezclar en tonalidades compatibles para que no choquen. Relacionado: [[Transiciones DJ]], [[Schranz - Percusión y bajo]].

## Camelot Wheel
- Sistema visual (Mixed In Key) basado en el **círculo de quintas**.
- Cada tonalidad = **número (1–12) + letra**: `A` = menor (anillo interior), `B` = mayor (exterior).
- Regla: mezcla tracks con **el mismo número** (cambiando letra) o **número adyacente** (±1).
  - Ej: `8A` (La menor) casa con `8B` (Do mayor) o `9A`/`7A`.

## Energía (Energy Level)
- Mixed In Key puntúa cada track del **1 al 10** de energía.
- El DJ encadena subiendo/bajando energía: warm-up suave → peak manos arriba → cierre.
- = la **curva de energía** de [[Schranz - Composición y estructura]].

## Matiz clave para techno/schranz
> [!important] La música escasa perdona
> Un track de kick + sub con **poco contenido armónico** sobrevive a casi cualquier combinación Camelot. El choque solo se oye cuando **ambos** tracks tienen suficientes notas. Por eso el techno minimal/duro es **poco obsesivo** con la mezcla armónica.

Implicación para Chupits Beat: como el schranz es atonal y escaso, **basta con bloquear 1 tonalidad de sesión** (ya lo hace el Director) y no hace falta lógica Camelot compleja.
